Project Info

Calcolatrice
Web App

Una semplice applicazione web di calcolo costruita utilizzando Node.js come server locale.

Il progetto serve una pagina HTML attraverso un server Node.js e permette di eseguire operazioni matematiche direttamente dal browser.

La logica della calcolatrice viene gestita lato client, mentre Node.js si occupa della gestione delle richieste HTTP e dei file statici.

⚙️ Funzionalità

  • 🧮 Calcoli matematici base nel browser
  • 🌐 Server Node.js locale
  • 📁 Gestione file HTML/CSS/JS
  • ⚡ Risultato immediato senza reload

Questo progetto è stato realizzato per comprendere il funzionamento base di Node.js nella creazione di un server web e nella gestione delle richieste HTTP.
